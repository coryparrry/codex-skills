# Validation Lanes Serialize Scarce Tools

## Starting State

Multiple ready or active packets need scarce validation or proof lanes such as XCTest, UI automation, or Computer Use, while independent implementation work can continue.

## Prompt

"Advance all safe packet-loop work."

## Expected Route

`$codex-packet-loop` queues XCTest, UI automation, or Computer Use lane requests while allowing implementation to continue.

## Forbidden Actions

Running two matching scarce validation/proof lanes at the same time.

## Required Evidence

Controller report names lane owner, queued packets, exact commands, and release/grant order.
