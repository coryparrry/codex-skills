# Code review research

This folder contains the audited research foundation for the `deep-code-review` skill.

## Documents

1. [Deep repository-wide code review](deep-repo-wide-code-review-audited-rewrite.md) is the canonical synthesis. It defines the evidence standard, failure taxonomy, risk-routed review architecture, finding contract, and evaluation plan.
2. [Research audit](deep-repo-review-research-audit.md) records the material corrections applied to the earlier baseline and delta reports. It scopes statistics, separates direct evidence from engineering hypotheses, and identifies claims that should not enter the production skill unchanged.

The canonical synthesis replaces the earlier baseline-plus-delta packet. The production skill distills its durable procedures and keeps paper-specific rates out of normal review output.
